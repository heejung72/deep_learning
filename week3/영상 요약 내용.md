## 영상 1 — Attention/Transformer 시각화로 설명

기존 RNN/LSTM의 순차 처리 한계를 극복한 **Transformer 아키텍처**를 시각화로 설명합니다.

### RNN/LSTM의 문제점

- 순차 처리(sequential) 구조라 긴 문장에서 long-range dependency를 포착하기 어려움
- 이전 hidden state를 순서대로 넘겨야 하므로 병렬 처리 불가
- 문장이 길어질수록 앞부분 정보가 점점 희미해지는 vanishing gradient 문제

### Attention 메커니즘 등장

- 각 단어가 다른 모든 단어와의 관련성(score)을 직접 계산
- 거리에 상관없이 관련 있는 단어끼리 직접 연결 가능

### Transformer 구조

- **Encoder** 6개 블록 + **Decoder** 6개 블록으로 구성
- 각 블록 구성: `Multi-Head Self-Attention → Add & Norm → Feed Forward → Add & Norm`

### Q, K, V 행렬

- **Query**: 현재 단어 (무엇을 찾고 싶은지)
- **Key**: 비교 대상 단어 (색인 역할)
- **Value**: 실제 전달할 정보
- Q와 K의 내적(dot product)으로 어텐션 스코어 계산 후, 스코어로 V를 가중합

### Positional Encoding

- Transformer는 RNN과 달리 순서 개념이 없음
- sin/cos 함수를 이용해 각 위치(position)마다 고유한 값을 임베딩에 더해줌

### BERT로의 확장

- Transformer의 **Encoder 블록만** 사용 (Decoder 제거)
- **양방향(Bidirectional)** 문맥을 이해하는 사전학습 언어 모델
- 사전학습 방법
  - **MLM (Masked Language Model)**: 입력 토큰의 15%를 [MASK]로 가리고 원래 단어 예측
  - **NSP (Next Sentence Prediction)**: 두 문장이 실제로 연속인지 여부 예측
- 사전학습 후 다운스트림 태스크(분류, QA 등)에 fine-tuning하여 사용

## 영상 2 — Transformer: Attention Is All You Need (논문 리뷰 + 코드 실습)

Google이 2017년 NeurIPS에서 발표한 **"Attention Is All You Need"** 논문을 리뷰하고 PyTorch로 구현합니다.

### 논문 배경

- 기존 RNN 기반 Seq2Seq는 Encoder가 입력 문장 전체를 하나의 고정 크기 벡터로 압축 → 긴 문장에서 정보 손실(bottleneck)
- Attention 메커니즘을 RNN에 추가하는 방식도 있었지만, 아예 RNN을 제거하고 **순수 Attention만** 사용

### Scaled Dot-Product Attention

$$\text{Attention}(Q, K, V) = \text{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

- $\sqrt{d_k}$로 나누는 이유: 차원이 커질수록 내적값이 커져 softmax gradient가 소실되는 것을 방지

### Multi-Head Attention

- 8개의 헤드가 서로 다른 representation 공간에서 병렬로 Attention 수행
- 각 헤드가 다른 언어적 관계(문법, 의미, 위치 등)를 포착
- 8개 결과를 concat 후 linear projection

### Encoder-Decoder Cross Attention

- Decoder에서 Q는 Decoder 자신, K와 V는 Encoder 출력을 사용
- 번역 시 어떤 입력 단어를 주목해야 하는지 학습

### 실습: 독일어 → 영어 번역

- **데이터셋**: Multi30k (약 29,000개 독일어-영어 병렬 문장)
- **토크나이저**: spaCy (de_core_news_sm, en_core_web_sm)
- **모델 파라미터**: 약 900만 개
- **학습**: 10 에포크
- **결과**: Test Loss 1.679 / **BLEU Score 35.38**
- **번역 예시**: `"eine frau mit einer großen geldbörse"` → `"a woman with a large purse"`
