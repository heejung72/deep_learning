# 용어 정리

## Transformer 핵심 구조

| 용어 | 설명 |
|------|------|
| **Self-Attention** | 문장 내 모든 토큰이 서로의 관련성을 계산하는 메커니즘. RNN 없이도 문맥 파악 가능 |
| **Q (Query)** | 현재 단어. "이 단어가 다른 어떤 단어와 관련 있는가?"를 묻는 역할 |
| **K (Key)** | 비교 대상 단어. Query와 내적(dot product)하여 어텐션 스코어 계산 |
| **V (Value)** | 실제 전달할 정보. 어텐션 스코어로 가중합하여 최종 출력 생성 |
| **Scaled Dot-Product Attention** | $QK^T / \sqrt{d_k}$ 로 스케일링 후 softmax → gradient 소실 방지 |
| **Multi-Head Attention** | h개의 Attention을 병렬 수행 → 문법·의미·위치 등 다양한 관계 동시 포착 |
| **Positional Encoding** | RNN이 없어 순서 정보가 없으므로 sin/cos 함수로 위치 정보를 임베딩에 직접 주입 |
| **Add & Norm** | Residual Connection + Layer Normalization. 학습 안정화 및 기울기 소실 방지 |
| **Feed Forward** | 각 Attention 블록 뒤에 붙는 2층 완전 연결 신경망. 각 위치(position)마다 독립 적용 |

## BERT 관련

| 용어 | 설명 |
|------|------|
| **BERT** | Bidirectional Encoder Representations from Transformers. Transformer Encoder만 사용하는 사전학습 언어 모델 |
| **Encoder-only** | Transformer의 Encoder 블록만 사용. 양방향 문맥 이해에 특화 (BERT, RoBERTa 등) |
| **Decoder-only** | Transformer의 Decoder 블록만 사용. 텍스트 생성에 특화 (GPT 시리즈 등) |
| **MLM (Masked LM)** | BERT 사전학습 방법 ①. 입력 토큰의 15%를 [MASK]로 가리고 원래 단어 예측 |
| **NSP (Next Sentence Prediction)** | BERT 사전학습 방법 ②. 두 문장이 실제로 연속인지 여부를 이진 분류로 예측 |
| **[CLS] 토큰** | 문장의 맨 앞에 추가되는 특수 토큰. 분류 태스크에서 문장 전체의 표현으로 사용 |
| **[SEP] 토큰** | 문장 구분자. NSP에서 두 문장을 구분하는 특수 토큰 |
| **Fine-tuning** | 사전학습된 BERT를 특정 태스크(분류, QA 등)에 맞게 추가 학습 |

## 번역 실습 관련

| 용어 | 설명 |
|------|------|
| **Seq2Seq** | Sequence-to-Sequence. 입력 시퀀스를 다른 시퀀스로 변환하는 구조 (번역, 요약 등) |
| **Multi30k** | 약 3만 개의 독일어-영어-프랑스어 병렬 코퍼스. Transformer 번역 실습에 자주 사용 |
| **BLEU Score** | Bilingual Evaluation Understudy. 기계번역 품질 평가 지표. 0~100이며 높을수록 좋음 |
| **Tokenizer** | 문장을 토큰(단어/서브워드) 단위로 분리하는 도구. 실습에서는 spaCy 사용 |
| **Cross Attention** | Decoder에서 Encoder의 출력을 참조하는 Attention. Q=Decoder, K·V=Encoder 출력 |
